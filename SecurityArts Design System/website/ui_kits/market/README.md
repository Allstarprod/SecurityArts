# UI kit — Market (the marketplace)

A faithful recreation of the **SecurityArts marketplace** — where sealed original works are bought and licensed — composed from the design-system components.

- **Entry:** `index.html` (loads React, `assets/genart.js`, the compiled `_ds_bundle.js`, then `MarketApp.jsx`).
- **Source of truth:** `SecurityArts/market.html` in the provided codebase.

## Screen
- **App bar** — brand + "Market" tag, live **search**, link to Discover, and a **Cart** button with item count.
- **Intro** — "Own work made by a *human hand*."
- **Toolbar** (sticky) — medium `Chip`s + a `Select` sort (Featured / Price ↑ / Price ↓).
- **Product grid** — responsive grid of `ProductCard`s (4:5 art with `VerifiedBadge` + quick-view overlay, title/price, artist·medium, add-to-cart). Empty state when nothing matches.

## Interactive flows
- **Quick view** (`Modal`) — large artwork + three `LicenseOption` tiers (Personal / Commercial 3× / Exclusive 9×); add the selected tier to the cart.
- **Cart** (`Drawer`) — line items with thumbnail, artist, license, price; remove items; live subtotal; proceed to checkout.
- **Checkout** (`Modal`) — order summary + payment `Field`s, then a sealed **order confirmation** (order id, count, total). `Toast` confirms adds.

## Components used
`Seal`, `Icon`, `Input`, `Select`, `Chip`, `Button`, `Field`, `ProductCard`, `VerifiedBadge`, `LicenseOption`, `Drawer`, `Modal`, `Toast`.

## Notes
Prices derive from a deterministic base per work; licensing math is Personal ×1 / Commercial ×3 / Exclusive ×9. Artwork is generated by `assets/genart.js`. Checkout is a demo — no card is charged.
