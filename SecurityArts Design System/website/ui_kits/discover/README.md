# UI kit — Discover (the verified wall)

A faithful recreation of the **SecurityArts discovery wall** — where verified human-made art is browsed, saved, and submitted for sealing — composed from the design-system components.

- **Entry:** `index.html` (loads React, `assets/genart.js`, the compiled `_ds_bundle.js`, then `DiscoverApp.jsx`).
- **Source of truth:** `SecurityArts/discover.html` in the provided codebase.

## Screen
A single app view:
- **App bar** — brand + "Discover" tag, a live **search** `Input`, links to Market, a **Boards** button with saved count, and a `Get verified` CTA.
- **Intro** — "A wall of work no machine *made*."
- **Filter bar** (sticky) — medium `Chip`s + a live count.
- **Masonry wall** — a CSS-column grid of `Pin`s (glass `VerifiedBadge`, hover save-to-board button, rising title/artist overlay). Empty state when filters match nothing.

## Interactive flows
- **Search + filter** — live text search across title/artist/medium, combined with the medium chips.
- **Boards** (`Drawer`) — create named boards, pick the active board, and save/unsave pins into it; counts update live. `Toast` confirms.
- **Get verified** (`Modal`) — "seal a sample piece" generates a `Certificate` (algorithm, hash, signature, signer, timestamp), then **Publish to the wall** prepends your work as an `own` pin. `Toast`: "Published — your work is on the wall".

## Components used
`Seal`, `Icon`, `IconButton`, `Input`, `Chip`, `Button`, `Field`, `Pin`, `Drawer`, `Modal`, `Certificate`, `Toast`.

## Notes
Artwork is generated by `assets/genart.js` (the product's own deterministic generator) — replace with real uploads in production. The seal certificate is a client-side demo; production signs server-side and posts the hash to a public registry.
