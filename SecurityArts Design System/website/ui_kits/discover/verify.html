Verify a SecurityArts seal

A SecurityArts seal is an ECDSA P-256 signature over one exact file's SHA-256 hash, made by the SecurityArts key at upload time. To check a seal, compute the SHA-256 of the original file (shasum -a 256 file.png on macOS/Linux, certutil -hashfile file.png SHA256 on Windows) and look it up in the public registry. A match tells you which key signed those exact bytes and when; a re-saved or re-exported copy hashes differently and will not match.

The check runs in this page's script; the same answer is available as JSON from GET /api/verify/<sha256> and the signing public key from GET /api/seal/pubkey.
