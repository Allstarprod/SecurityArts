## 1. Security (`server/`) — ranked

### CRITICAL
1. **Standalone `server.mjs` serves the repo root.** `server.mjs:24` `ROOT = repo root`; `serveStatic :35-57` has traversal guard, no allowlist. Verified: `GET /server/.env` 200 (DB password, seal private key, service key), `/server/data/seal-key.pem`, `/session.secret`, `/db.json` (all users), `/audit.log`, `/.git/HEAD`. Vercel unaffected. **Render (`render.yaml:14`) affected.** Fix: explicit public root + hard-deny `server/ .git/ .github/ .claude/ api/ supabase/` + dotfiles; regression test asserting 404.
2. **Verify UI fabricates results.** `verify.app.js:31-39` PRNG seals, never calls `/api/verify`; `seal.app.js:277,282` fake hash/signer; `:253-260` "Re-verify" = `setTimeout`; `:54-64` fake provenance/sales. Fix: call `GET /api/verify/:hash`, render `work.cert.*` verbatim, one real timeline event.

### HIGH
3. **Anonymous sealing of arbitrary bytes.** `routes.mjs:355-383` no auth, no `data:image/` check; `blobstore.mjs:56` trusts client MIME (html/svg accepted → hosted on your bucket). No delete/admin route. Fix: require user, sniff magic bytes (PNG/JPEG/WebP), derive Content-Type, per-user quota, owner delete + admin takedown.
4. **`/api/checkout` = unauthenticated email relay.** `routes.mjs:536-563` arbitrary `email`, free-text item interpolated into receipt from `MAIL_FROM`; `status:"paid"` unconditionally → fake revenue in `/api/me/sales`. Same on `/api/auth/register:141`. Fix: disable or auth-gate; validate ids; `pending` until payment webhook.
5. **No session revocation.** `auth.mjs:49-70` stateless `{uid,exp}` 7d; logout/reset don't invalidate. Login limiter per-IP only. Fix: `sessionVersion` in token + per-account lockout.
6. **Seal key: no rotation, hash-only signature.** `seal.mjs:52-55,70-74,78-87`; `ts`/`signer`/id unsigned. Docs claim HSM/KMS; reality plaintext env var. Fix: key registry `{kid,pubkey,validFrom,validTo}`, canonical payload `SA-SEAL-v1|hash|ts|kid`, verify against `cert.signer` key, KMS.
7. **Pre-account takeover via Google merge.** `routes.mjs:128-146` no email verification; `:245-254` merges Google login by email. Fix: verify email; store `google_sub`.

### MEDIUM
8. CSP wildcards `*.supabase.co` in `connect-src` (browser never talks to Supabase) + `'unsafe-inline'`. `security.mjs:23-27`, `vercel.json`.
9. Rate limiter: first-hop XFF (`security.mjs:110-119`), fails open (`ratelimit.mjs:56-61`).
10. scrypt N=2^14 sync (`auth.mjs:35,42`); OWASP floor 2^17.
11. Prod secrets plaintext in `server/.env` + `server/.env.vercel` on workstation. Gitignored, not in zips.
12. `PUBLIC_BASE_URL` unset in all deploy targets (`routes.mjs:22-26`).
13. PII in audit logs + Sentry unscrubbed (`routes.mjs:157,194,556,581`, `sentry.mjs:42-43`).

### LOW
14. Double-hash canonicalization undocumented (`seal.mjs:69-72`) — `openssl dgst -verify` on raw file mismatches. 15. OAuth no PKCE/`aud` check. 16. Unbounded rows on nonexistent work ids (`routes.mjs:436-495`). 17. `decodeURIComponent` 500 (`server.mjs:36`). 18. `engines >=18`. 19. `CORP: same-origin` blocks future badge embed. 20. e2e not idempotent on file DB.

**Clean:** all SQL parameterized; scrypt + `timingSafeEqual` + dummy hash; hashed single-use reset tokens; CSRF Origin + SameSite; body caps; generic 5xx; order IDOR fixed; zero `innerHTML`; `npm audit` 0; no secrets in tracked files or zips.

**Process note:** the audit's redaction missed digit-containing key names; `SEAL_PRIVATE_KEY_B64` and DB password values were printed into the subagent transcript on this workstation. Rotate DB password + service_role key. Audit also wrote 2 junk works + 1 order to untracked `server/data/db.json` / `audit.log`.
