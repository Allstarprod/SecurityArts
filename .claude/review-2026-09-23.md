## Needs an owner decision (not fixed; outside the new pages or the API)

1. **CRITICAL: Terms and Privacy say SecurityArts "verifies human-made artwork".** Examples: `terms.html:58`, `terms.html:66-72` ("warrant that a human created it"), and `privacy.html:52`. The sign-up page asks people to agree to these. They need rewriting in guardrail language plus legal review. §5 (licences) matches code that exists in `routes.mjs`, so check whether checkout is live before cutting it.
2. **CRITICAL: Pricing claims live on the old site.** `pricing.jsx` ($5/$15/mo, a 10% fee, "Most popular"), `faq.html:48,182` ("free"), and `create.jsx:151` ("Pricing & fees"). The new pages no longer link to them, but they are still reachable.
3. **HIGH: The welcome email says "prove it's yours, collect verified human art"** (`server/routes.mjs:258-263`). This is a one-line server copy change; the plan says the API stays untouched, so it needs a yes.
4. **HIGH: Email and Google links return to the old login page.** See `LOGIN_PATH` in `routes.mjs:18` and lines 246, 289 and 404. Once join.html ships, point the verify, reset and Google return links at it.
5. **HIGH: Every conversion leaves at /create (the old design).** Rebuild seal-a-piece next.
6. **HIGH: /how-it-works is the most-linked old page.** Its buttons go to the old sign-up. `/verified` is titled "Prove your art is human".
7. **MEDIUM: The production CSP blocks the homepage's Three.js import from cdn.jsdelivr.net**, so the hero seal would vanish. Vendor three.js into the repo; don't widen the CSP.
8. **MEDIUM: The API invents a medium per category** (every painting is "Oil on linen"). The wall shows only the category.
9. **MEDIUM: The API returns `ownerId` but no handle**, so the viewer needs one extra request per piece. Adding `ownerHandle` to `/api/works` would remove it.
10. **MEDIUM: The Privacy notice leaves out** Google sign-in, Google Fonts, public display of sealed works, and PostHog/Sentry on the old pages.
11. **LOW: The dev app server listens on all interfaces** (`server.mjs:117`), so it is reachable from the local network.
