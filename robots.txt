# AI crawler access policy. Last reviewed: 2026-09-20
#
# POSTURE (default chosen — see tradeoff at the bottom):
#   1. Search engines and AI *answer/citation* crawlers: allowed everywhere except /api/.
#      These drive discovery and citations, which is the whole point of the content layer.
#   2. AI *training* crawlers: allowed on the marketing/explainer pages, blocked on the
#      surfaces that carry artists' images (the wall, seal records, profiles, feed).
#      Artists seal work here specifically to prove it is human-made; letting training
#      crawlers ingest that work would contradict the platform's promise.
#   3. Known aggressive scrapers that ignore or abuse robots: blocked outright.
#
# NOTE: robots.txt is advisory. Enforcement for crawlers that ignore it (Bytespider is
# widely reported to) belongs in the Vercel Firewall / WAF rules, not here.
# NOTE: artwork bytes are served from Supabase Storage (*.supabase.co). This file cannot
# govern that host. The training-crawler block below covers the HTML pages that embed
# and link the images, not the image origin itself.

# TRADEOFF — training crawlers (decide once, document it here)
#
# Option A (chosen above): allow training on marketing/explainer pages, block it on
#   artist-content surfaces.
#   + Pages that explain the product are eligible to be learned and cited by future
#     models; the artists' images are not offered up.
#   + Consistent with the brand promise to artists and with the community the
#     platform is courting (the same community that left platforms over AI training).
#   - Slightly more complex file; per-path rules must be kept in sync with vercel.json
#     rewrites when routes change.
#
# Option B: allow all training crawlers everywhere (except /api/).
#   + Simplest; maximum exposure for a pre-traction site.
#   - Offers sealed human artwork to training sets. Expect this to be raised by
#     artists and to undercut the "proof a human made it" positioning.
#
# Option C: block all training crawlers everywhere.
#   + Strongest content-licensing stance.
#   - GPTBot and ClaudeBot also feed the models' background knowledge of who
#     SecurityArts is; blocking them makes the brand less likely to appear in
#     answers that are not backed by live search. For a new brand this cost is real.
#
# Google-Extended and Applebot-Extended are opt-out tokens (no crawler uses them as a
# user agent); listing them here is how you tell Google/Apple not to use fetched
# content for AI training. Search indexing is unaffected.
# ---------------------------------------------------------------------------
