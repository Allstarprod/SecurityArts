01 Verify

Check a seal. No account needed.

Drop in a file, or paste its fingerprint. We'll tell you whether that exact file was sealed on SecurityArts, by which account, and when.

Check a file

Drop the file you want to check

or choose a file · it stays on your device

A fingerprint is the SHA-256 of the exact file: 64 characters, 0–9 and a–f.

Fingerprint · SHA-256

What a check tells you

A match means this exact file was sealed on SecurityArts: you'll see which account sealed it, when, and a link to its certificate. It doesn't tell you who made the art, or whether it's original.

No match means the file was never sealed here, or it's a copy that has been re-saved, resized, re-encoded or screenshotted. A copy has different bytes, so it never matches. Ask for the original file.

Check it without us

Every seal is an ECDSA P-256 signature over the file's SHA-256 fingerprint. The public key is at /api/seal/pubkey, and the seal spec explains how to check a signature yourself.
